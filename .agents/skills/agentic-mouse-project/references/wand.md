## Lounging distance and readable text

Ethan: “we'll probably be sitting pretty far back from the screen when using the magic wand ... because we're chilling.” Account for that distance in every wand UX decision, including floating instructions, notifications, wedge labels and adjustment feedback. Prefer large, clear text using the available space; do not enlarge the wedges to compensate. Keep labels roughly horizontal and upright, using modest angles only where they make a specific label easier to read. Judge actual rendered cases individually, including long labels and outer cards. Improve the shared text-fitting rules as new cases are verified, rather than accumulating separate label-specific layouts or treating a fitting box as proof of readability. Inspect the screenshots themselves at normal HUD size and retain useful examples. Preserve physical mouse layouts and behaviour. User-requested — 2026-10-30.

Verified fitting rules (`WandRadialText.swift`; the render harness writes `typography.txt` beside its PNGs): ring titles reach 30 pt, the centre 34, outer bands 28, floating reminders 22/15: one title line, then at most one smaller subtitle line whose short hints are separated by a vertically centred drawn dot with equal gaps (Ethan, 2026-10-30: “single line for title and then single line for the subtitle text ... separated by a dot ... vertically centered”); the pill widens to fit at full size and only a narrower visible screen shrinks a whole line evenly (`WandReviewIndicatorView`). At one size the fewest rows win, and extra rows must earn ≥2 pt and ≥15 % (no "Switch | App · | Choose"); the one exception is placement: a single row becomes two at the same size when that brings the block ≥24 pt closer to the card's visual centre (Codex's bottom-wedge "New | chat" instead of one row against the outer arc); taller stacks never grow for placement ("⇧ | Hold | Shift" would split the phrase). A slash compound may wrap after its slash only when it starts its row ("Play/ | Pause", never "… for Pin/ | Unpin"). Tilting must never lower the shared size of level neighbours. Outer bands use the same room-based fit with thinner margins, try level, then along-band and across-band readings gentlest first, share size only with same-layer siblings, and reserve end room for arrows when adjustable. Adjustment arrows keep 14 pt clear of every title row. Where a wheel order is free, give long single words (Brightness, Backspace) the level 3 or 9 o'clock wedges. The wand footer floats with no panel behind it, so its text is light with the cards' dark halo (`ModeHUDFooterLegibility`); the mice keep their system-secondary footer. Geometry-limited cases remain (Review changes / Stage files about 15.5 pt, New Codex chat 20 pt).
