OWNERSHIP, NOT MAGIC

Every layer has
one clear job.

  1. 01Vendor transport

    iCUE and the Razer onboard profile expose harmless, distinct raw controls.

  2. 02Karabiner semantics

    Exact-device rules turn the two transports into one physical action vocabulary.

  3. 03Agentic Mouse runtime

    A signed menu-bar app owns modes, HUDs, lighting and focus-aware application shortcuts.

  4. 04Visible result

    Native output reaches macOS while a source-aware legend explains the active layer.
