A personal build, with a few things to know

No public binary release. Build the app yourself and set up Karabiner and iCUE by hand. The proprietary iCUE SDK is not bundled. Some controls still need physical acceptance; the previews keep those marked.

Custom commands are designed to stop when the Mac locks or the session becomes uncertain. A website demonstration is not a physical acceptance test. Read the limitations and verification notes before copying the setup.
