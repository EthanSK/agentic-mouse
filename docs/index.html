NO MAGIC / NO MYSTERY DAEMON

EVERY LAYER HAS ONE JOB.

  1. HARDWAREThe mice send neutral keys

    iCUE exposes distinct Corsair keypad transports; the Razer's exact interface exposes its commissioned key transports. Neither owns the final action.

  2. MAPPINGKarabiner emits native input

    Each mouse has its own guarded route to normal macOS keys, media controls and shortcuts.

  3. RUNTIMEAgentic Mouse owns state

    Ethan's locally signed menu-bar app runs modes, independent HUDs, lighting and focus-aware app shortcuts.

  4. SECURITYUnlocked or nothing

    A short expiring lease gates custom commands and fails closed on lock, sleep, crash or uncertain state.

Compatibility reality: Corsair's public SDK does not document macOS support, and Razer's standard LampArray path did not control this mouse. Ethan's setup uses an audited Corsair framework build and a physically accepted, unofficial Razer vendor-report lighting route. This is an open personal build, not vendor-supported software.

THE PART I REFUSED TO FAKE

IF IT ISN'T SAFE, IT DOESN'T FIRE.

LOCKED SESSIONThe generated rules and runtime consume custom side-grid, DPI and mode commands unless the session is positively unlocked. Automated coverage is complete; final physical lock-screen acceptance is still open.

UNCERTAIN FOCUSText actions fail closed instead of guessing where to type.

APP FAILUREShort leases expire and restore the ordinary map automatically.

STEAL THE GOOD BITS

BUILD YOUR OWN AGENTIC SETUP.

You probably do not own my exact desk, my exact two mice or my exact tolerance for twelve-button grids. Fine. The repository explains the architecture and build path so you can take the useful parts. It does not currently publish a signed or notarized binary release. The map above documents Ethan's installed personal build; some corresponding implementation work is still local and has not landed on public main, so a fresh clone is not presently identical to that build.

git clone https://github.com/EthanSK/agentic-mouse.git
cd agentic-mouse
make check
make app  # development-only ad-hoc bundle; see docs/SETUP.md

The proprietary iCUE SDK is not bundled. The audited build path currently expects Corsair's 4.0.84 framework. Hardware mappings, Accessibility approval and physical acceptance remain specific setup work—not a one-click installer.
