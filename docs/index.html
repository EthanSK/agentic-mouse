THE NON-NEGOTIABLES

Local, legible, reversible.

  • 01No hidden profile edits. Vendor apps stay the source of truth for their own hardware.
  • 02No home data in a repo. Bridge keys, device IDs and room names stay local.
  • 03Typing fails closed. If focus is uncertain, Agentic Mouse sends nothing.
