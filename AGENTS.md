# Agentic Mouse project rules

- This repository owns the source/build architecture for shared named Karabiner actions across Ethan's Corsair Scimitar and left-handed Razer Naga, plus the Scimitar's explicit classic phone multi-tap mode and temporary runtime indicator.
- Preserve the existing working iCUE assignments, 2,750 DPI, Logitech setup, Karabiner rules, VoiceInk++ route, and all unrelated hardware and application settings.
- The authoritative global mapping is Ethan's latest accepted shared map: wheel click = Play/Pause through an exact-device Karabiner rule on both mice; physical cells 1 and 4 are the horizontal-scroll pair (left/right); cell 2 = Switch App; cell 3 starts or cancels selected-area Screenshot outside modes; cell 5 = ordinary Forward with a VS Code Previous Change override; cell 6 = an app-specific wildcard that is silent by default and performs one-press Stage + Next in VS Code; cell 7 = Enter outside runtime modes; cell 8 = ordinary Back with a VS Code Next Change override; cell 9 opens Keys mode; cell 10 toggles the persistent Default legend outside modes and is the universal Exit while any mode is active; cell 11 opens the mode for the current frontmost app; cell 12 opens Utility modes; and the top DPI control triggers VoiceInk++ speech-to-text without changing the fixed 2,750 DPI. Mirror the Razer by physical cell, not printed number: screenshot cell 3 is Corsair printed 3 / Razer printed 1; app-shortcut cell 6 is Corsair printed 6 / Razer printed 4; Keys mode cell 9 is Corsair printed 9 / Razer printed 7; universal exit/legend cell 10 is Corsair printed 10 / Razer printed 12; Utility modes cell 12 is Corsair printed 12 / Razer printed 10. One unfiltered base rule per mouse applies in every application, with only explicit app overrides and matching base exclusions. A runtime mode may intercept these keys only while explicitly active and must restore the global mapping on exit. (Codex task: 019fd41a-b89f-7de1-8795-bd7e3de7dfdd)
- Never edit iCUE's private database/profile files directly. Live iCUE changes must be performed visibly and verified through the app.
- Keep exactly one canonical iCUE software profile for the Scimitar. It owns DPI, lighting, and the neutral side-grid/DPI transports for every application. Never create or duplicate app-linked iCUE profiles for semantic behavior; app-specific overrides belong in exact-device Karabiner conditions or Agentic Mouse modes. Extra software profiles are a regression because an empty profile can silently remove every neutral transport.
- Treat an inactive or locked macOS session as a hard security boundary. Agentic Mouse must renew only a short absolute-expiry unlocked-session lease from documented `NSWorkspace` session notifications; every generated command must require that lease both when its manipulator matches and when delayed/release output fires. When the lease is absent, expired, or explicitly cleared, an exact-device sink must consume all Corsair and Razer neutral side-grid, DPI, and custom wheel transports so they cannot leak into the lock screen. Lock, fast-user-switch, screen sleep, app failure, and lease-write failure must tear down modes, HUDs, pending text, and synthetic actions immediately. Unlock may restore only the idle runtime baseline, never a prior mode, HUD, pending action, or queued key release. Preserve ordinary pointer motion, scrolling, and primary/secondary clicks as normal macOS input.
- Package every build intended to replace Ethan's `/Applications/AgenticMouse.app` with the stable `Developer ID Application: Ethan Sarif-Kattan (T34G959ZG8)` identity via `CODE_SIGN_IDENTITY`; never install an ad-hoc replacement. An ad-hoc designated requirement is the changing code hash and silently invalidates the app's Accessibility grant on every rebuild. Never reset TCC or invoke `sfltool` for this workflow; verify the signed requirement, let Ethan grant the stable app once in System Settings, and preserve that identity/path on future installs.
- Keep semantic actions separate from physical bindings. Agentic Mouse may generate Karabiner-compatible output, but no Corsair or Razer position enters the binding file or live Karabiner profile until Ethan approves that exact physical-cell choice and the exact-device source event has been captured.
- Preserve layered ownership: iCUE owns Corsair hardware settings and neutral transports; the Naga onboard profile owns its hardware transports; enabled exact-device mappings live in Karabiner; Agentic Mouse owns semantic source files, generation, and explicitly approved runtime modes. Never store a live profile, private serial, or second hidden mapping source here.
- Philips Hue-to-mouse mirroring is retired. Do not restore its runtime, configuration, network access, or UI.
- Target only the exact Scimitar device discovered at runtime. Never apply SDK lighting to all Corsair devices.
- Use shared iCUE SDK lighting control. Do not request exclusive lighting control. Runtime input comes from exact-device Karabiner `send_user_command` press/release phases; do not add a parallel raw iCUE semantic-input source. Keep the older `CAL_ExclusiveKeyEventsListening` transport source-only unless a separately approved diagnostic requires it.
- Multi-tap mode must be visibly and behaviorally modal, must not activate or focus its reference HUD, and must restore the normal mouse behavior immediately on exit, disconnect, or process failure.
- The Default mode legend is a one-click toggle on physical cell 10: Corsair printed 10 / Razer printed 12. Each mouse owns an independent legend: pressing that mouse's Legend toggle again hides only its copies, while the other mouse's legend may remain visible in parallel. Corsair legends sit bottom-right; left-handed Razer legends sit bottom-left. Each shows one non-activating panel on every connected display, requires no Accessibility permission, takes no Karabiner mode lease, and never changes mouse lighting or ordinary mappings. Keep user-facing copy concrete (`Default mode`, `Legend toggle`); never expose internal terms such as `passive reminder` as HUD labels. The Legend toggle card exists only inside the visible legend, so keep that stable control name instead of switching it to `Hide legend`. Screenshot copy is the deliberate exception to next-action wording: use `Screenshot` while idle and `Cancel screenshot` while an interaction is running. Never guess when state belongs to an external app Agentic Mouse cannot observe reliably.
- Physical cell 3 (Corsair printed 3 / Razer printed 1) owns selected-area Screenshot outside modes. The first press starts one native interactive screenshot process and the next press cancels only that still-running process; completion or Escape clears the session so a later press starts fresh. Lock, sleep, reload, and app shutdown must also cancel the exact process. Never represent screenshot state with an unbounded timer or a stale latch.
- Physical cell 12 (Corsair printed 12 / Razer printed 10) opens Utility modes. The first Utility page lists only implemented utility actions: physical cell 7 enters Keypad and cell 11 opens the lower-priority manual configured-app selector. Every active mode exits through universal physical cell 10 (Corsair printed 10 / mirrored Razer printed 12), which toggles the Default legend outside modes. App-specific children keep cell 12 available for a real app action; they never reserve it as a second back or exit control. Colour Proof has completed validation and must not appear as a generated rule or selectable slot; keep its proven controller source only as internal regression infrastructure. Future modes stay in the outstanding ledger until their trigger, action map, colour, and exit are wired.
- On the first Utility page, physical cell 1 decreases macOS screen brightness, physical cell 2 increases it, physical cells 3/6 move one macOS Space left/right, physical cells 4/5 send the standard Command-Minus / Command-Plus zoom shortcuts to the frontmost app, physical cell 7 enters Keypad, physical cell 8 asks the existing VoiceInk YouTube Bridge to rewind the correctly targeted YouTube video by five seconds without focusing Chrome, physical cell 9 enters Keys mode, and physical cell 11 opens the manual configured-app selector. Utility cards show only the concise action title and the small source-mouse button label; omit explanatory subtitle/detail copy such as `Open native arrow keys`. Emit deterministic brightness, zoom, and Space actions as non-repeating native events from the exact-device Karabiner layer and let Agentic Mouse update only HUD/lighting state; reserve app-side execution for the YouTube bridge. Post one bounded down/up cycle per utility press; use the exact no-payload Distributed Notification `com.ethansk.agenticmouse.youtube.seekBackwardFiveSeconds` for rewind; keep the Utility page open; and never let these utility actions leak into Keypad or app-specific child modes.
- The Razer lower DPI button keeps its onboard F22 transport and the Corsair top DPI button uses its named iCUE F19 neutral transport. Both exact-device Karabiner adapters trigger VoiceInk++ only on source release. Do not claim physical release timing for either mouse until EventViewer proves one down at press and one up at physical release; preserve the official iCUE export and the prior generated/live Karabiner backup as rollback.
- Every runtime mode must have a distinct, strongly saturated intentional colour, must exit through universal physical cell 10, and must show the floating legend on every connected display for the whole mode lifetime. Use the current mode colour for every card border and each action family's colour for that card's fill, with selection expressed by stronger border weight and opacity rather than a different border hue. Related pairs or groups must share one fill: Brightness Down/Up, Zoom Out/In, Space Left/Right, all four arrow keys, and any equivalent future family. Unrelated controls retain distinct fills. Default mode is the neutral baseline and uses white card borders, never the blue runtime accent. Keep both roles opaque enough that the mode and selection remain bold over macOS materials; do not dilute the hardware mode colour into a pastel. Every card content stack must keep an explicit 12-point horizontal inset inside its border; grid spacing and a two-line limit do not substitute for internal padding. Do not reserve an in-mode Legend toggle cell; cell 10 exits and closes the mode HUD. Corsair and Razer use separate coordinators, presenters, and Karabiner lease variables so both HUDs and different modes can coexist without changing each other's routing, lighting, or ordinary map. If that mouse's persistent top-level legend was visible before mode entry, restore it after exit; otherwise close its mode HUD on exit. Make the main function the prominent card text and put one small printed button label for the exact source mouse underneath it.
- Every shared HUD must retain canonical physical cells internally and render only the active source mouse's printed labels. Never duplicate or renumber the semantic map to achieve presentation-only numbering.
- Match the accepted G502 Better Git gesture in both exact-device VS Code layers: physical cell 5 single-click emits F17 Previous Change and double-click emits F19 Stage + Previous; physical cell 8 single-click emits F13 Next Change and double-click emits F18 Stage + Next. Use a 300 ms window, keep every output non-repeating, and preserve ordinary Forward/Back outside VS Code.
- Draw every 4 × 3 mouse HUD from the top of the mouse toward the desk. The right-handed Corsair uses canonical rows `3/6/9/12`, `2/5/8/11`, then `1/4/7/10`. The left-handed Razer reverses each row for the horizontal mirror: `12/9/6/3`, `11/8/5/2`, then `10/7/4/1`. Keep the `1/4/7/10` physical row at the bottom and change presentation only, never the canonical semantic cells.
- Keypad is selected from Utility modes with physical cell 7. It follows the familiar classic-phone layout: cell 1 cycles punctuation, cells 2–9 carry ABC through WXYZ (including DEF on physical cell 3), and a long hold on cells 1–9 emits that digit. Universal cell 10 exits; tap cell 11 to cycle `abc → Abc → ABC → 123 → abc`; tap cell 12 for Space and hold it for Return. Show every punctuation character in a compact multi-row preview rather than clipping the long cell-1 cycle. Its exact-device press/release stream must remain focus-anchored and fail closed.
- Top-level physical cell 11 opens the current frontmost app's mode directly and refreshes its HUD when the frontmost application changes. Utility cell 11 opens the separate manual selector (Codex, Chrome, and VS Code); selecting an app locks that target without activating it, and later focus changes must not retarget that manual journey. Press universal cell 10 to exit from the selector or any app child. Deliver shortcuts through one generic, bounded `CGEvent.postToPid` adapter selected by bundle identifier; only each app's shortcut meanings are app-specific. Codex provides New Task, Pin/Unpin, Mute/Unmute voice microphone, Start Voice Mode, Steer Queued Message, Enter, Start New Voice Chat, and Reasoning Effort Up/Down. Preserve Codex's built-in keyboard shortcuts; only commands with no existing binding may receive additive dedicated Hyper-function-key bindings. Name `composer.startVoiceMode` as Start Voice Mode rather than implying that it also stops an active voice session. Do not substitute Codex's `openSideChat` command for opening the newest queued message in side chat: current Codex exposes the latter only as a row-menu action, not as a configurable command, so it must remain honestly unavailable until Codex exposes a real shortcut or command. Chrome cell 1 closes the current Chrome window with Command-W. Keep every unimplemented card honestly Spare; never activate a target app to simulate background delivery.
- Keys mode opens directly from top-level physical cell 9. Corsair physical cells 5/4/7/1 emit Up/Down/Right/Left; on the left-handed Razer, cells 1 and 7 deliberately swap the horizontal meanings so the physical gestures are mirrored. Physical cell 6 copies, cell 3 pastes, cell 9 emits Next Track, cell 8 emits Space, and cell 11 emits Backspace. Do not duplicate top-level Enter inside Keys mode. Physical cell 2 types the optional device-local password directly from macOS Keychain without using the clipboard, configuration files, generated rules, or logs; it must fail closed when locked, untrusted, or unconfigured. Press universal physical cell 10 to exit. Emit keys and the consumer-media event natively in the generated exact-device Karabiner layer, keep every output non-repeating, let Agentic Mouse update only HUD/lighting state, and restore the ordinary map immediately on exit or lease failure.
- Keep the reusable mode legend at 75% of its former 940-point design (705-point width with proportionally scaled typography, spacing, padding, corners, and strokes). It has no large header or instructional subtext. Put the action first on every card, then one small printed label for the exact mouse that opened it; never show both devices on the same card. Use one compact bottom row for the mode title and active mouse.
- Default text entry to buffered pending-character commit, anchored to the frontmost PID and focused AX element. A focus/element change cancels pending text. Never use an unanchored global backspace-and-replace loop as the safe default.
- Runtime mode colours are temporary output only. While Agentic Mouse is running, maximum solid white is the baseline on both mice whenever no explicit mode or alert is active; mode colours override it and exit returns to white. The Scimitar exposes only logo plus the complete thumb-grid zone; the Naga exposes wheel, logo, plus the complete thumb-grid zone. Use the logo/wheel for the current mode colour and the whole grid for the last-action accent; never claim twelve independent LED buttons. A true app teardown or sleep still releases the Corsair shared layer and restores Razer Spectrum so vendor ownership is never stranded. Never present this as a Mural, profile, or device-memory editor.
- Do not store credentials, application keys, tokens, bridge addresses, device IDs, serials, generated app bundles, or downloaded vendor binaries in Git.
- Keep hardware, event-source, text-output, state-machine, and UI boundaries injectable so core behavior can be tested without a connected mouse, Accessibility permission, or iCUE.
- Do not commit, push, publish, install a LaunchAgent, alter Accessibility permissions, or mutate live hardware/settings unless Ethan has separately authorized that exact step.
- Run focused tests and a clean build before declaring implementation complete. Record any untestable hardware boundary honestly.
