## Product and Ethan's setup

- This repository owns the source/build architecture for shared named Karabiner actions across Ethan's Corsair Scimitar and left-handed Razer Naga, plus the Scimitar's explicit classic phone multi-tap mode and temporary runtime indicator.
- Preserve the existing working iCUE assignments, 2,750 DPI, Logitech setup, Karabiner rules, VoiceInk++ route, and all unrelated hardware and application settings.
- Never edit iCUE's private database/profile files directly. Live iCUE changes must be performed visibly and verified through the app.
- Keep exactly one canonical iCUE software profile for the Scimitar. It owns DPI, lighting, and the neutral side-grid/DPI transports for every application. Never create or duplicate app-linked iCUE profiles for semantic behavior; app-specific overrides belong in exact-device Karabiner conditions or Agentic Mouse modes. Extra software profiles are a regression because an empty profile can silently remove every neutral transport.
- Treat an inactive or locked macOS session as a hard security boundary. Agentic Mouse must renew only a short absolute-expiry unlocked-session lease from documented `NSWorkspace` session notifications; every generated command must require that lease both when its manipulator matches and when delayed/release output fires. When the lease is absent, expired, or explicitly cleared, an exact-device sink must consume all Corsair and Razer neutral side-grid, DPI, and custom wheel transports so they cannot leak into the lock screen. Lock, fast-user-switch, screen sleep, app failure, and lease-write failure must tear down modes, HUDs, pending text, and synthetic actions immediately. Unlock may restore only the idle runtime baseline, never a prior mode, HUD, pending action, or queued key release. Preserve ordinary pointer motion, scrolling, and primary/secondary clicks as normal macOS input.
- Package every build intended to replace Ethan's `/Applications/AgenticMouse.app` with the stable `Developer ID Application: Ethan Sarif-Kattan (T34G959ZG8)` identity via `CODE_SIGN_IDENTITY`; never install an ad-hoc replacement. An ad-hoc designated requirement is the changing code hash and silently invalidates the app's Accessibility grant on every rebuild. Never reset TCC or invoke `sfltool` for this workflow; verify the signed requirement, let Ethan grant the stable app once in System Settings, and preserve that identity/path on future installs.
- **A USER-REQUESTED AGENTIC MOUSE CHANGE IS NOT COMPLETE UNTIL IT IS LIVE.** After the requested source change passes the minimum build, packaging, signature and live-state checks required for a safe install, automatically package one stable Developer-ID candidate, advance the real marketing version and build number exactly once, preserve the current installed bundle as a recoverable rollback, send one native macOS heads-up, record which source-specific Default legends are visible, send the app's idempotent source-specific close command to both mouse coordinators before replacing the selected Karabiner block even when no mode lease remains, install only `Karabiner/generated/agentic-mouse-runtime.json`, cleanly terminate only the exact running Agentic Mouse app through its dedicated `Quit Agentic Mouse` menu item, replace `/Applications/AgenticMouse.app`, relaunch that exact path, and read back the installed signature, version, executable hash, embedded iCUE SDK hash, running PID, command-socket ownership, and relevant live-config/Karabiner preservation. After the active-session input gate is ready, restore exactly the Default legends that were visible before the attended replacement and verify one HUD per connected display; restarting the app clears this in-memory presentation state, so zero HUD windows is not a correct handoff when Ethan had left a legend open. For Ethan’s small personal app workflow, notify him “New version installed”, then run the full gate and applicable installed review afterward; installation is not final verification. Never install the five-rule `agentic-mouse.json` base export: it can still open modes but omits the active-mode routing and universal Exit rule. A generic AppleEvent Quit bypasses the dedicated supervisor-disarm path, and reloading Karabiner while a runtime mode is active resets the mode variables before the HUD receives Exit; a missing lease therefore does not prove that every HUD closed. Never use either unsafe sequence during installation. Do not stop at a green source candidate, ask for a second install approval, or leave Ethan running the previous build merely because installation is a separate script step. A request to change or fix this app authorizes this normal signed install/relaunch completion step. Stop before installation only when Ethan explicitly says source-only/no-install/not-now, when a real safety or ownership conflict remains, or when an external user-only permission blocks completion; report that exact boundary immediately. Automated checks and a successful install still do not replace any genuinely physical behavior acceptance.
- Keep persistent runtime recovery on the supported signed nested `SMAppService.loginItem` helper packaged at `Contents/Library/LoginItems/AgenticMouseSupervisor.app`. It may relaunch an unexpectedly absent main app through non-activating `NSWorkspace` with bounded backoff, crash-loop protection, and the per-user main-process instance lock. Defer relaunch while loginwindow or the screensaver owns the session. Every launch, display wake, or transition away from loginwindow must remain fail closed until a public global event monitor proves real input while a normal app is frontmost; loginwindow activation must clear the lease immediately. Explicit Quit must use Service Management's asynchronous unregister completion so the running supervisor is killed before main-app termination, and must cancel Quit if disarming recovery fails; a normal unexpected `SIGTERM` remains recoverable. Do not replace this design with `SMAppService.mainApp`, a LaunchAgent, private service files, process-name polling, a marker-file convention, a private lock-state key, or a relaunch path outside the exact containing signed app. Preserve locked-session teardown across every restart.
- Keep semantic actions separate from physical bindings. Agentic Mouse may generate Karabiner-compatible output, but no Corsair or Razer position enters the binding file or live Karabiner profile until Ethan approves that exact physical-cell choice and the exact-device source event has been captured.
- Treat Ethan naming a `Corsair n` or `Razer n` button as a reference to that button's canonical physical cell, not as permission to create device-specific semantics. He may switch mice and name whichever printed label is under his thumb. Resolve the named label through the crosswalk and apply the requested semantic change to both mice. Diverge only when Ethan explicitly asks the mice to behave differently for a stated hardware, handedness, transport, lighting, or presentation reason; merely naming one mouse is never enough. Preserve transport key codes, printed HUD labels, independent HUD corners, and lighting calibration. The one-cell top-level Copy/Paste and Horizontal Scroll wheel chords use the same accepted wheel polarity on both mice; only Keys arrows retain the explicit left-handed Razer horizontal projection.
- Preserve layered ownership: iCUE owns Corsair hardware settings and neutral transports; the Naga onboard profile owns its hardware transports; enabled exact-device mappings live in Karabiner; Agentic Mouse owns semantic source files, generation, and explicitly approved runtime modes. Never store a live profile, private serial, or second hidden mapping source here.
- Philips Hue-to-mouse mirroring is retired. Do not restore its runtime, configuration, network access, or UI.
- Target only the exact Scimitar device discovered at runtime. Never apply SDK lighting to all Corsair devices.
- Use shared iCUE SDK lighting control. Do not request exclusive lighting control. Runtime input comes from exact-device Karabiner `send_user_command` press/release phases; do not add a parallel raw iCUE semantic-input source. Keep the older `CAL_ExclusiveKeyEventsListening` transport source-only unless a separately approved diagnostic requires it.
- Show the packaged Agentic Mouse marketing version and exact build number in every legend footer. Read both from the running app bundle, never hard-code them in the view. Every successfully signed candidate intended for local installation must advance both identifiers exactly once after packaging and signature verification: increment the patch component of `CFBundleShortVersionString` by default and increment the positive-integer `CFBundleVersion`. A named major/minor release may supply a higher explicit marketing version, but no install may reuse or lower the recorded marketing version. Failed candidates and ordinary ad-hoc development builds must consume neither identifier. Persist both resulting source values as the installed-build reference.
- Do not store credentials, application keys, tokens, bridge addresses, device IDs, serials, generated app bundles, or downloaded vendor binaries in Git.
- Never print tokens into logs, tool output or diagnostic files. Do not dump environments or full process arguments: use PID, PPID and executable columns (`ps -axo pid=,ppid=,comm=`), and redact necessary captured text in memory before printing or saving it. App-owned utility children use `ChildProcessEnvironment.minimal`; log destinations use `LogRedaction` rather than trusting each caller to remember.
- Keep hardware, event-source, text-output, state-machine, and UI boundaries injectable so core behavior can be tested without a connected mouse, Accessibility permission, or iCUE.
- Ethan gives standing authorization to stage, commit, and push every completed Agentic Mouse source change to this repository's current branch without asking him to review or stage it. After the full gate and live completion, automatically stage every safe task-owned repository change, commit it, push it to `origin`, and verify the remote commit. Exclude credentials, application keys, tokens, bridge addresses, device identifiers, live Karabiner profiles, `Rollbacks/`, generated app bundles, downloaded vendor binaries, and other local/private artifacts from the public repository. Do not absorb ambiguous unrelated or incomplete work; reconcile ownership first and stop only when it cannot be separated safely. This standing publication authority does not authorize a LaunchAgent, Accessibility changes, unrelated hardware/settings, iCUE mutation, or device firmware changes.
- Run focused tests and a clean build before declaring implementation complete. Record any untestable hardware boundary honestly.
